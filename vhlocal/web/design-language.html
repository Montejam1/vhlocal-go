Design language · first pass

Instrument

vhlocal is not a dashboard. It is a measuring instrument that reports what it actually observed, refuses to overclaim, and shows its working. The interface should read the same way: calm, dense, precise, and honest about the difference between what the engine measured and what a model asserted.

Reference points Apple restraint · Qualys density Resolution Apple's discipline applied to Qualys' density Constraint no webfonts — reports ship offline
01

Two rules carry the system

Everything below derives from these. If a decision doesn't follow from one of them, it's decoration and it gets cut.

Warm ink is reserved for what the scan found. Everything the tool says about itself is cool.
Severity is the only thing allowed to be warm — crimson, orange, amber. Progress bars, active states, links, focus rings, charts of durations and token counts all wear petrol. So a warm pixel anywhere on screen means a finding, always. Today the same blue does duty for progress, links, severity-adjacent chrome, and every bar chart, so colour carries no meaning at all.
Prose is set in sans. Every piece of evidence is set in mono.
File paths, file:line citations, CWE ids, durations, token counts, model names, hashes — all mono, all tabular figures. The product's entire claim is that a finding without a citation is invalid. Making evidence typographically distinct from commentary encodes that claim in the type system rather than asserting it in a README. It also does the work a display face would normally do, which matters because reports must render offline with no font loading.

The severity ramp is measured, not chosen by eye

Measured properly, the dark ramp's weak point was not normal vision at all — it was deuteranopia, where High and Medium collapsed to ΔE 12.2, well under the 15 floor. Red, orange and amber fall on one axis for a deuteranope, so hue buys nothing there; only lightness separates them. This ramp is stepped on lightness first, which is also what makes it brighter.

Two honest caveats. Light-mode Medium still sits just under 3:1 — amber on white cannot clear it while staying amber and 15 apart, which is why the reference palette documents the same relief; the mitigation is the glyph-plus-word badge, which already ships. And Medium is a pale yellow rather than a saturated amber by necessity, not taste: for a deuteranope orange and yellow lie on one axis, so moving Medium toward yellow moves it toward High. Saturated ambers fell to ΔE 10–12 there. This ramp buys the yellow back by stepping Critical and High as well — the three were solved together, not one at a time — which lands deuteranopia at 15.1, just over the floor.

03

The signature: the phase spine

A scan is six phases with wildly uneven durations, any of which can degrade. The spine is one horizontal measure — segment width is real elapsed time, fill is state. It is the live progress indicator during a run, and the same mark becomes the run's fingerprint on its report card afterwards. You learn to read a scan's shape at a glance.

06

What actually changes

Today

  • One blue (#6d8bff) for progress, links, focus, and every chart — colour carries no meaning
  • Severity High/Medium at ΔE 12.2 under deuteranopia, below the legibility floor
  • System sans for everything; mono demoted to a caption face
  • Panels nested in cards nested in panels; 8/12/16px radii read soft
  • Gradient-filled bars, decorative rather than encoding
  • Six phases shown as equal-weight chrome, hiding a 26-of-28-minute reality

Instrument

  • Warm = findings, cool = the tool. A warm pixel always means something
  • Severity re-stepped to ΔE 30.4 normal / 15.1 worst-CVD, measured not eyeballed
  • Mono promoted to a co-lead role: it marks evidence
  • Hairline rules over nesting; 3/5/7/10px radii read precise
  • Flat fills; width and length do the encoding
  • The phase spine — proportional, stateful, and the same mark everywhere

Nothing here is committed to the app yet. This page is the whole proposal — it lives on the ux-redesign branch, so backing it out is one git checkout main.
